# v0.3: evidence and U.S. readiness crosswalk

The user wants the downloadable tool to gather useful evidence and crosswalk current U.S. AI frameworks and policies. Build an expandable evidence engine, not a claim that this endpoint can certify the organization or exhaust every jurisdiction.

1. Keep bounded, opt-in, read-only collectors; add safe version and MCP setting facts without credentials, raw names, commands, URLs or document scraping.
2. Add optional structured applicability and control-evidence questions. Missing answers stay unknown. A user statement is never independently verified evidence.
3. Ship a dated source registry distinguishing voluntary frameworks, government policy and legal review triggers. Include current primary-source links, effective-date caveats, explicit scope exclusions and source-review expiry. This is a selected initial catalog, not all U.S. law.
4. Produce authored, provision-linked readiness mappings with observation references, gaps, recommended owner, deliverable and verification. No compliance score or automatic legal applicability verdict.
5. Render the same crosswalk in the guided UI, HTML and JSON. Keep prior comparison behavior and schema-1 compatibility.
6. Test unknown/negative inputs, applicability combinations, stale sources, traceability, HTML escaping and secret exclusion. Verify browser and packaged builds before delivery.

Next expansion: selected local policy/evidence documents with explicit selection, per-use-case inventory and jurisdiction profile, structured evidence references and reviewer decisions, more state/sector packs, and a separately authorized update workflow with reviewed catalog changes. No automatic web text ingestion as executable rules. Broad enterprise discovery requires separately authorized connectors.
